# Vainilla JavaScript Template

Starter template for vanilla HTML, CSS and JavaScript projects.

## Included

- Webpack
- ESLint
- Prettier
- Development server
- CSS support
- Asset handling

## Getting started

Install dependencies:

```bash
npm install
```

## How to use

1. Create a new repository from this template.
2. Clone the repository.
3. Install dependencies with `npm install`.
4. Start developing with `npm run dev`.
